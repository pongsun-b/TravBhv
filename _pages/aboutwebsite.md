# About this website

This is the public site of the Travel Behavior Research Group at the Department of Civil Engineering, Chulalongkorn University. It is a Jekyll site hosted on GitHub Pages. Group members, publications, and news are stored as YAML files in `_data` and rendered by the layouts in this repository.

The page is unpublished and is not linked from the main navigation.
